# 处理器输入是按槽位解析的数据视图，而非 Resolved World 整体

**Status**: accepted (2026-10-02, Spec Lock #6)

处理器的每个输入槽位由解析器提供一份只读的数据视图（可能来自作者数据、生成数据，或二者的合并结果），因此处理器图只含「数据 → 处理器 → 数据」三类边，可在入图时静态检查无环。charter §56 的注解允许 Resolved World 作为处理器输入；若按字面实现，处理器就能读到自己经过解析后的输出，形成无法静态检测的环，并使 Rebuild 结果依赖求值顺序。

## Considered Options

- **允许 Resolved World 整体作为输入**：表达更直接，但需要运行期环检测、迭代上限与失败策略。
- **只允许原始数据项作为输入**：最安全，但用户手绘数据无法进入下游推导（违反 charter §12）。

## Consequences

槽位解析成为解析器的一项职责；手绘河仍能经槽位进入下游处理器（14 步验收之第 10 步）。
