# 抑制匹配 = lineageId 精确匹配；过期抑制显式可见

**Status**: accepted (2026-10-02, Spec Lock #6)

对象级抑制按生成对象的 `lineageId`（由处理器、参数、seed 与输入哈希确定性决定）精确匹配；上游变化导致该 id 不再出现时，抑制被标记为「已过期」并在调试 / 冲突视图显式可见，**不做模糊几何匹配**。理由是用户删除派生结果的意图（charter §17/§20）必须稳定可预期：几何容差会把「删了又回来」换成更糟的「删错了别的对象」，而身份消失时系统应当如实告知用户，而不是假装成功。

## Considered Options

- **几何容差匹配**：更贴合「我删的就是这条河」的直觉，但阈值微调后会错杀新对象，容差参数也没有客观标准。
- **只做空间级抑制**：实现最简单且没有身份问题，但丢失 charter §18 要求的对象级语义。

## Consequences

空间级抑制（不依赖身份）被鼓励作为更稳的默认语义；该裁决直接决定实现票 #10 的验收用例。
